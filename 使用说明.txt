  FuckZhihuishuPro - 智慧树刷课助手 使用说明
════════════════════════════════════════════

【这是什么】
智慧树（知到）刷课助手。免 Python、免浏览器、双击即用。
- 支持扫码登录（知到 APP）和账号密码登录
- 自动刷共享学分课、校内学分课
- 课中弹题自动作答
- 默认平台最高倍速，无需任何设置
- 关掉窗口后最小化到托盘，后台继续刷

【怎么用】
1. 双击运行 FuckZhihuishuPro.exe
2. 用知到 APP 扫二维码登录（推荐）
   （也可以切到"账号登录"输账号密码）
3. 在"我的课程"里勾选要刷的课程 → 点"开始刷课"
4. 想去干别的？直接关窗口，程序缩到屏幕右下角托盘
   继续刷。托盘左键点图标恢复窗口，右键菜单可退出
5. "刷课进度"页可以实时看到每门课的进度条和自动答题记录

【第一次打不开？往下看】
1. 如果 Windows 弹蓝色提示"Windows 已保护你的电脑"：
   → 点"更多信息" → 点"仍要运行"
   （程序是开源学习工具，未购买数字签名所以有此提示）
2. 如果被电脑管家 / 杀毒软件拦截：
   → 选择"允许"或"添加信任"即可
3. 系统要求：Windows 10（较新版本）或 Windows 11，
   正常更新过的电脑都自带运行所需组件，无需额外安装
4. 用 QQ / 微信传文件时请先打成压缩包再发，直接发 exe
   可能被传输软件改名或拦截

【数据保存在哪 / 怎么清空】
登录状态和配置保存在程序目录的 FuckZhihuishuPro-Data
文件夹（部分电脑系统会自动存到 AppData）。删除对应文件
夹即可清空全部本地数据。程序不上传任何数据到第三方。

【macOS 用户】
1. 下载 .dmg 拖入"应用程序"，首次打开请右键 → 打开（未签名提示）
2. 登录请用"扫码登录"（"浏览器登录"仅 Windows 提供）

【小提示】
- 部分账号第一次在非常用设备登录需要短信验证：
  先用浏览器登录一次智慧树网页版，之后再用本工具即可
- 默认倍速已是平台允许的最高值；设置页可以调更高，
  但更快意味着被风控的风险更高，请自行权衡
- 如果刷课中提示"触发验证码"，去智慧树网页或 APP
  完成一次验证，再回到本程序继续

仅供学习交流使用，请合理安排时间，该学的内容还是要学。
